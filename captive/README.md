# Каптив-заглушка «сонный мотылёк»

Страница, которая сама вылезает при подключении к фестивальному WiFi. Мотылёк
просыпается, ноет и зазывает нажать на лампу — лампа уводит на основное
расписание.

`index.html` — весь экран целиком: разметка, стили, персонаж (SVG) и звук.
**Ни одного внешнего запроса**: на каптиве интернета ещё нет, любой CDN/шрифт
превратился бы в дырку в вёрстке. 29 КБ одним файлом.

## Как потрогать локально

```bash
python3 -m http.server 8123 --directory captive
# открыть http://127.0.0.1:8123/
```

Тапнуть куда угодно — мотылёк просыпается. Тапнуть по лампе ещё раз — уходит
на `CFG.url`.

## Звук

Озвучки нет и записывать её некому, поэтому голос **синтезируется на месте**
через WebAudio — по «блипу» на слог, в духе Animal Crossing. Плюс щелчок
выключателя, тёплый гул горящей лампы, зевок и звоночек на нытьё. Челюсть
перестаёт жевать ровно тогда, когда смолкает последний блип: `Snd.speak()`
возвращает свою длительность, по ней и снимается класс `talking`.

Громкости сведены и померены через `OfflineAudioContext` (пик по сэмплам):

| звук | пик | заметка |
|---|---|---|
| голос | 0.115 | опорный уровень, остальное под него |
| щелчок лампы | 0.13 | короткий, шум через highpass |
| зевок | 0.108 | шум через «поющий» bandpass |
| звоночек | 0.081 | две синусоиды |
| гул лампы | 0.021 | фон, тихо и непрерывно |
| **вся сцена разом** | **0.169** | запас по громкости есть, клиппинга нет |

Если захочется перевесить баланс — правь `vol`/`gain` в модуле `Snd` и
перемеряй тем же способом, цифры выше воспроизводимы.

**Живые реплики.** Запишете голос — киньте mp3 в `captive/audio/` под именами
из `CFG.wake[].file` / `CFG.nags[].file` и поставьте `CFG.files = true`.
Синтез останется запасным вариантом, если файл не догрузился.

`CFG.tts` (SpeechSynthesis) намеренно **выключен**: на разных телефонах голоса
разные и звучит криво, а в каптив-вебвью этого API часто просто нет.

Справа сверху — тумблер звука, состояние живёт в `localStorage`
(`insomnia.captive.muted`). Тумблер намеренно **не будит** мотылька: звук
должно быть можно выключить заранее.

## Что было починено в исходном прототипе

1. **Первый тап по лампе сразу уводил на сайт, героиня не успевала сказать ни
   слова.** `pointerdown` на `document` приходит раньше, чем `click` на кнопке:
   он ставил `awake = true`, и обработчик кнопки проваливался сразу в
   `location.href`. Теперь тап, которым разбудили, «съедается» (`swallowClick`,
   окно 700 мс).
2. **`speechSynthesis?.cancel?.()` падал с ReferenceError** в вебвью, где этого
   API нет: `?.` защищает от `null`/`undefined`, но не от необъявленного
   идентификатора. Исключение летело до `location.href`, и кнопка молча
   переставала работать. Теперь `window.speechSynthesis` + `try/catch`.
3. **Падение звука убивало всю страницу.** Исключение из `ensure()` вылетало
   через `unlockAudio()` наверх из `wake()` — до `body.classList.add('awake')`,
   причём `awake` уже стоял в `true`, так что следующие тапы не помогали:
   экран намертво зависал на спящем мотыльке. Публичные методы `Snd` теперь
   обёрнуты в `try/catch` — звук это украшение, кнопка важнее.
4. Копирование адреса не работало по http: `navigator.clipboard` живёт только
   в secure context, а каптив — это всегда `http://`. Добавлен фолбэк через
   `execCommand('copy')`.

Проверено в Chrome: тумблер звука не будит → первый тап будит и **не**
переходит → реплика появляется → второй тап переходит.

## Развёртывание на GL-AXT1800

Роутер уже стоит: `192.168.8.1`, комп в его LAN. Прошивка GL.iNet 4.x
(OpenWrt 21.02), LuCI доступен на `http://192.168.8.1/cgi-bin/luci` —
**это проверено**. Всё, что ниже, требует SSH и пока **не проверено на живом
роутере**.

### Шаг 1. Разведка (что вообще есть на борту)

```sh
ssh root@192.168.8.1
opkg list-installed | grep -iE 'nodogsplash|opennds|coova|uhttpd'
ls /etc/config/
df -h /overlay          # сколько места под пакеты
```

Плюс глянуть в GL-админке (не LuCI) раздел Applications — у GL.iNet бывает
свой каптив-портал, и если он есть, городить ничего не надо.

### Шаг 2а. Если есть/ставится opennds — правильный путь

```sh
opkg update && opkg install opennds
mkdir -p /etc/opennds/htdocs
# положить index.html туда
uci set opennds.@opennds[0].gatewayinterface='br-lan'
uci commit opennds && /etc/init.d/opennds restart
```

Это даёт настоящий каптив: телефон сам открывает заглушку, а после нажатия на
лампу клиент авторизуется и получает выход в интернет.

### Шаг 2б. Фолбэк — dnsmasq + uhttpd

Если `opennds` не встаёт (репозиторий GL.iNet может не отдать пакет под
21.02 — это главная точка риска), можно перехватить DNS:

```sh
uci add_list dhcp.@dnsmasq[0].address='/#/192.168.8.1'
```

Проще, но грубо: заворачивает **все** домены на роутер, интернет через него
уже не пройдёт. Годится, если раздаём только расписание.

### Шаг 3. Чем проверять

Заглушка вылезает не потому, что страница открывается по `192.168.8.1`, а
потому, что у телефона **не проходит проба связи**. Проверять надо именно их:

* Android — `http://connectivitycheck.gstatic.com/generate_204` (ждёт 204)
* iOS/macOS — `http://captive.apple.com/hotspot-detect.html` (ждёт `Success`)
* Windows — `http://www.msftconnecttest.com/connecttest.txt`

Пока эти три не заворачиваются на нашу страницу — каптив не работает,
чем бы ни отвечал корень роутера.

## Два ограничения, которые стоит держать в голове

1. **Кнопка «открыть расписание» ведёт на `hleserg.github.io` — значит роутеру
   на поляне нужен аплинк** (LTE-свисток или телефон по USB; AXT1800 умеет и
   то, и то). Без интернета уводить из каптива некуда: страница честно
   покажет адрес и предложит скопировать, но расписание не откроется.
2. **Раздать PWA прямо с роутера не выйдет.** Service worker и установка на
   «Домой» требуют secure context, а `http://192.168.8.1` им не является
   (localhost — исключение, LAN-адрес — нет). Избранное в приложении тоже
   живёт только в standalone-режиме. Поэтому схема именно такая: каптив —
   это витрина, а ставится приложение уже с настоящего https-адреса
   в системном браузере.
