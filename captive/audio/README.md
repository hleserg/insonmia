# Живые озвучки

Пусто — и это нормально: голос мотылька синтезируется на месте (см. `Snd`
в `../index.html`), файлы нужны только если запишете настоящие реплики.

Как подключить:

1. Записать mp3 (моно, 48 кбит/с — на каптиве всё качается с роутера).
2. Разложить под именами из `CFG` в `../index.html`:
   `wake1.mp3`, `wake2.mp3`, `wake3.mp3`, `nag1.mp3`, `nag2.mp3`, `nag3.mp3`.
3. Поставить `CFG.files = true`.

Синтез останется запасным вариантом: если файл не догрузился или не
декодировался, мотылёк просто пропищит реплику сам.
